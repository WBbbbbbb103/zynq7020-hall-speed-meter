# 小车测速三种方法：原理、接口与执行步骤

> 文档状态：方案总结与实施指南，2026-09-19
> 目标平台：LXB-ZYNQ7000（XC7Z020-2CLG484I）
> 现有器件：两只带 `DN/DS/AO` 的霍尔模块、8路3.3 V/5 V双向电平转换模块、Zynq XADC、TM1637。
> 证据标签：`DS_FACT`=工程/原理图已确认；`CALC`=给定假设下计算；`INFERENCE`=工程推断；`SIM`=仿真；`MEASURED`=有原始记录的测量；`TO_CONFIRM`=待确认。

## 结论先行

目前有三条测速路线：

1. **双霍尔四边沿 + 二次运动轨迹拟合**：改动最小，不用AO；能得到四边沿覆盖窗口内的速度函数，适合近似恒加速度运动，是保底方案。
2. **双路AO + 互相关/空间模板拟合**：利用完整磁场波形，提高传感器附近的局部速度和门间时延精度；仍不能直接观察两传感器之间AO平坦区域的任意运动。
3. **连续位置编码器 + 局部拟合/卡尔曼滤波**：把测量方式改为连续获得位置或相位，是“任意时刻速度”的正确主方案。可使用独立测量轮编码器；若尽量复用霍尔，可尝试磁环+双霍尔正交编码，但必须先验证波形。

选择原则：

```text
只需通过两门的速度，改动要小      → 方法1
要提高霍尔附近/门间时延精度        → 方法2
要从起步到停车连续输出任意时刻速度 → 方法3
```

三种方法并不互斥。最终系统可以用方法3连续输出速度，以方法1/2在固定位置做绝对校准和异常检查。

## 2. 测量定义

- **被测对象**：沿轨道运动的小车；磁铁固定在小车上，或编码器与小车/独立测量轮机械连接。
- **被测量**：指定时刻 `t_q` 的有符号速度 `v(t_q)=dx/dt`。方法1/2还需说明该时刻是否位于传感器有效窗口。
- **真实值**：连续车体位移的数学导数，无法由有限采样直接获得。
- **参考值**：独立光栅尺、激光位移计、经过标定的高速视觉或更高等级编码器给出的速度。
- **直接观测**：数字边沿时间戳、XADC码、编码器计数/相位、方向和故障标志。
- **间接结果**：门间平均速度、拟合速度/加速度/急动度、卡尔曼状态及置信度。
- **校准量**：四边沿空间位置、双AO空间模板、分压增益/偏置、编码器每圈计数、测量轮有效半径、时钟修正系数。
- **修正模型**：正反向独立边界/模板、AO增益和零偏、编码器比例系数、必要时温度和轮径修正。

“瞬时速度”在工程上始终是有限时间窗口内的估计，不是零时间宽度的数学测量。输出应包含：

```text
timestamp, direction, speed_mm_s, acceleration_mm_s2,
method_id, quality, uncertainty/status, valid
```

如果查询时刻处没有直接位置观测，输出只能标为“模型预测”；不能与传感器有效区内的直接更新混为一谈。

## 3. 系统框图

### 方法1：数字四边沿

```text
被测对象 → 磁场激励 → 霍尔A/B DN或DS
          → 电平转换模块 → G15/G16
          → 同步/稳定滤波 → A_ON/A_OFF/B_ON/B_OFF时间戳
          → 方向相关空间标定 → 二次轨迹WLS
          → v(t)、a、残差 → 显示/上传

模拟前端：N/A；只使用数字信号。
```

### 方法2：双路AO

```text
被测对象 → 磁场激励 → 霍尔A/B
          ├─ DN/DS → 电平转换 → 数字触发/方向/粗计时
          └─ AO → 模拟前端(10k:2k分压+4.7nF)
                 → VAUX0/VAUX8同步采样 → BRAM窗口
                 → 互相关/空间模板轨迹拟合
                 → 局部v(t)、门间时延、质量指标 → 显示/上传
```

### 方法3：连续位置编码器

```text
被测对象 → 测量轮/线性标尺/磁环激励 → 编码器A/B或sin/cos
          ├─ 数字AB → 电平转换/FPGA正交计数
          └─ 模拟sin/cos(若支持) → 分压/XADC → atan2相位细分
          → 连续位置x(t)或角度θ(t)
          → 局部多项式/PLL/卡尔曼滤波
          → 任意采样时刻v(t)、a(t)、置信度 → 显示/上传

方法1/2固定门 → 在已知位置校准方法3，并检查打滑/漂移。
```

统一基础：板载50 MHz时钟、3.3/5 V隔离边界、公共地、限流上电、独立参考校准和原始数据保存。

## 4. 方法比较

| 方法 | 适用条件 | 所需数据/硬件 | 优点 | 风险/限制 | 预计误差/速度 | 是否采用 |
|---|---|---|---|---|---|---|
| 1. 四边沿二次轨迹拟合 | 两固定霍尔能稳定产生ON/OFF，窗口内近似恒加速度 | 4时间戳、正反向共8个边界位置 | 改动最小；不用ADC；可估速度和加速度；有残差 | 只有4点；边界位置漂移主导；任意变加速和门间不可观测 | 50 MHz量化很小，最终由空间重复性决定 | **保底采用** |
| 2A. 双AO归一化互相关 | A/B波形形状相近，主要求传播时延 | 双路XADC和局部窗口 | 使用整段波形；亚采样时延；抗固定增益/零偏 | 长基线仍主要是平均速度；加速造成波形伸缩 | 需通过已知延迟和真实轨迹验证 | **提高精度初级** |
| 2B. AO空间模板轨迹拟合 | 轨迹、磁铁姿态和气隙可重复 | `g_A(x),g_B(x)`及波形 | 可测传感器附近局部速度；样本多；可拟合变加速 | AO平坦区不可观察；模板受机械变化影响 | 精度潜力高，机械重复性可能主导 | **提高精度主级** |
| 3A. 数字正交编码器 | 可安装编码器/测量轮，脉冲密度满足更新率 | AB编码器、计数/时间戳 | 连续位置；方向可靠；实现成熟 | 量化、轮径误差和打滑；低速更新慢 | 与线数、半径、拟合窗口有关 | **任意时刻主方案** |
| 3B. 双霍尔磁环 + AO相位细分 | 两AO能形成稳定近似sin/cos，机械允许重布置 | 磁环、双霍尔、XADC、椭圆校准 | 可复用部分器件；高更新率；数字AB可保底 | 现有模块是否适合未知；偏心/谐波/温漂；需要机械试验 | `TO_CONFIRM`，先原型验证 | 条件采用 |
| 3C. 固定门+IMU融合 | 不能装编码器但可加IMU | 加速度计+固定霍尔校正 | 门间可连续给预测速度 | 积分漂移、振动和坡度；属于状态估计 | 通常弱于连续位置编码器 | 备选 |

核心可观测性结论：如果A、B两门之间没有连续位置或加速度观测，且允许加速度任意变化，那么存在多条不同的中间速度曲线产生相同四个端点事件。此时任何算法都不能唯一恢复真实的 `v(t)`。

## 5. 误差预算

| 误差源 | 类型/分布 | 量级 | 传播/合成 | 证据 | 降低措施 | 剩余影响 |
|---|---|---|---|---|---|---|
| 50 MHz计时量化 | 随机/均匀近似 | 1 tick=`20 ns` | 等效位置约 `|v|σ_t` | `CALC` | 硬件时间戳 | 对毫秒级门事件通常非主导 |
| 霍尔数字边界重复性 | 随机+系统 | TO_CONFIRM | 作为位置协方差进入WLS | 待标定 | 固定气隙、正反向独立参数、多次重复 | 方法1主导项之一 |
| AO分压/ADC噪声 | 系统+随机 | 理想1 LSB=`244.1 µV` | 通过相关峰/模板雅可比传播 | `CALC`+`TO_CONFIRM` | 通道标定、归一化、合理限带 | 可能小于机械模板误差 |
| AO模板失配 | 系统 | TO_CONFIRM | 峰位/空间尺度变化导致速度偏差 | `INFERENCE` | 机械限位、方向/温度模板、残差拒绝 | 方法2主导项之一 |

| 测量轮有效半径 | 系统 | TO_CONFIRM | `u_v/v≈u_R/R` | 待校准 | 已知距离标定有效周长 | 比例误差 |
| 轮胎/测量轮打滑 | 粗差+系统 | TO_CONFIRM | 编码器位置与车体位置分离 | 机械条件决定 | 独立从动测量轮、固定门交叉校验 | 可能成为方法3主导项 |

| 局部模型带宽 | 系统 | 与窗口和急动度有关 | 长窗平滑动态，短窗放大噪声 | `INFERENCE` | 合成轨迹扫参、交叉验证、置信度 | 任意时刻估计的核心权衡 |

### 5.1 数字时间量化尺度

单时间戳均匀量化标准差：

`CALC: σ_t=20 ns/√12=5.77 ns`。

两个时间戳差：

`CALC: σ_Δt=√2×5.77 ns=8.16 ns`。

在 `5000 mm/s` 下的等效位移：

`CALC: σ_x,time=5000 mm/s×8.16 ns=4.08×10^-5 mm=0.0408 µm`。

因此方法1通常不是被50 MHz计数分辨率限制，而是被霍尔切换位置重复性限制。

### 5.2 XADC与分压尺度

采用每路 `10 kΩ/2 kΩ`：

`CALC: k=2 kΩ/(10 kΩ+2 kΩ)=1/6=0.166667 V/V`。

AO为5.5 V时：

`CALC: V_XADC=5.5 V/6=0.9167 V`，低于1.0 V设计满量程；1%电阻最坏值和保护细节见双AO完整方案。

理想12 bit码宽：

`CALC: q=1.000 V/4096=244.1 µV/code`，折算AO端约 `1.465 mV/code`。实际ENOB、噪声和AO源驱动为 `TO_CONFIRM`。

### 5.3 编码器空间分辨率

若测量轮半径为 `R`，每圈有 `P` 个AB电周期，四边沿计数：

`CALC: Δx=2πR/(4P), 单位 mm/count`。

示例仅用于尺度：`R=30 mm、P=60` 时：

`CALC: Δx=2π×30 mm/(4×60)=0.785 mm/count`。

这对高动态任意时刻速度仍较粗，说明方法3应优先使用高线数编码器、AO相位细分或更小测量轮，而不能只依赖少量磁极。

速度综合不确定度的一阶形式：

`CALC: u_v/v≈sqrt[(u_scale/scale)^2+(u_time/time)^2+(u_fit/v)^2], 单位为无量纲相对量`。具体数值需在确定编码器和验收指标后填写。

## 6. 方案

### 保底可完成方案

### 6.1 方法一：双霍尔四边沿 + 二次运动轨迹拟合

#### 原理

每只霍尔产生进入和离开两个数字边沿：

```text
A_ON, A_OFF, B_ON, B_OFF
```

标定每个边沿发生时车体参考点的空间位置。正反方向因迟滞和几何不同，使用两套参数，共8个位置。

一次通过得到4组 `(t_i,x_i)`。每次自动计算时间中心：

`t_c=(Σw_it_i)/(Σw_i)`，不需要物理标定；令 `τ_i=t_i-t_c`。

拟合：

`x_i=x_c+v_cτ_i+0.5a_cτ_i²+ε_i`。

矩阵解：

`θ_hat=(H^TWH)^-1H^TWx`，`θ=[x_c,v_c,a_c]^T`。

得到整段模型：

`v(t)=v_c+a_c(t-t_c)`。

因此可计算四边沿窗口内任意时刻的模型速度，但离中心越远、模型失配风险通常越高。窗口外属于外推。

#### 执行步骤

1. 数字接线：霍尔A `DN/DS→B0↔A0→G15`；霍尔B `DN/DS→B1↔A1→G16`；电平板 `VCCA=3.3 V、VCCB=5 V`，全部共地。
2. 扩展现有输入逻辑，从滤波后的 `hall_active` 生成ON和OFF两个单周期事件。
3. 用64 bit、50 MHz全局计数器锁存四类事件；采用四位接收掩码，不硬编码唯一事件顺序。
4. 正反向各慢速移动至少20次，记录四个空间边界的均值、标准差和相关性。
5. 先在PC实现浮点WLS，使用合成匀速/恒加速度时间戳验证。
6. 再在PL定点实现：时间中心化、归一化到约 `[-1,1]`，求解3×3系统。
7. 检查事件完整性、方向、速度范围、加速度范围、矩阵条件和残差；失败则回退原门间平均速度或报无效。
8. 与独立速度参考做多速度、多方向重复验收。

#### 能力边界

- 优点：硬件最少、计算量小、原工程可渐进改造。
- 能测：门事件覆盖窗口内、近似恒加速度条件下的速度函数。
- 不能可靠测：两门间任意变化的加速度；用4点拟合三次曲线会无残差并严重放大噪声。

### 提高精度方案

### 6.2 方法二：双路AO + 互相关/空间模板拟合

#### 原理A：归一化互相关

对两段AO波形去均值、除标准差：

`z_A[n]=(A[n]-mean(A))/std(A)`，`z_B[n]=(B[n]-mean(B))/std(B)`。

计算：

`R[k]=Σ_n z_A[n]z_B[n+k]`。

找到峰值整数延迟 `k_0`，再做三点抛物线插值：

`δ=0.5[R(k_0-1)-R(k_0+1)]/[R(k_0-1)-2R(k_0)+R(k_0+1)]`。

`CALC: τ_hat=(k_0+δ)/f_s, 单位 s；v_avg=d_eff/τ_hat, 单位 mm/s`。

互相关利用整段波形，通常比单阈值稳定，但直接结果仍主要是A到B的传播时延/平均速度。

#### 原理B：空间模板轨迹拟合

慢速位置扫描建立：

`AO_A=g_A(x)`，`AO_B=g_B(x)`。

正式通过时拟合：

```text
J = Σ[A_n-α_Ag_A(x(t_n))-β_A]²
  + Σ[B_n-α_Bg_B(x(t_n))-β_B]²
```

近似恒加速度可用二次 `x(t)`；变加速时，在每个霍尔有效区采用局部三次：

`x(t)=c_0+c_1τ+c_2τ²+c_3τ³`。

窗口中心：

`v(t_0)=c_1`，`a(t_0)=2c_2`，`j(t_0)=6c_3`。

AO提供大量采样点，因此三次拟合仍有充分残差可用于检查，不像四数字点拟合四参数那样刚好插值。

#### 执行步骤

1. 先断开FPGA，用示波器确认两路AO的空载/加载范围、极性、噪声和是否超出0–5.5 V设计包络。
2. 每路AO经 `10 kΩ/2 kΩ` 分压和 `4.7 nF`，绕过电平转换模块。
3. AO_A接 `VAUX0P/N=F16/E16`，AO_B接 `VAUX8P/N=D16/D17`；Hall B数字信号必须改至G16。
4. 配置XADC Wizard为VAUX0+VAUX8同步、单极性、初始100 kSa/s/通道、扩展采集时间。
5. 数字ON事件触发BRAM局部环形窗口；不保存低速时两门之间全部空白数据。
6. 用同源波形标定两XADC通道固定延迟，用精密直流源标定增益和偏置。
7. 正反向慢速位置扫描，各至少20次，建立 `g_A(x),g_B(x)`及波形方差。
8. 先做互相关和亚采样峰值，取得粗速度/初值；再做模板二次或局部三次拟合。
9. 用相关峰值、模板残差、饱和状态和数字四边沿结果联合判定有效性。
10. 在独立验证集上选择窗口长度、滤波和拒绝阈值，最后做整机验收。

#### 能力边界

- 优点：使用整段波形，局部精度潜力高，适合发现变加速。
- 能测：A、B磁场有效区附近的局部速度，以及门间传播时延。
- 不能直接测：两传感器之间 `dg/dx≈0` 的AO平坦区域；该区只能靠运动模型预测。

### 6.3 方法三：连续位置编码器 + 局部拟合/卡尔曼滤波

这是满足“从起步到停车、任意时刻查询速度”的主方案。

#### 硬件选择顺序

1. **线性光栅/磁栅**：直接测车体相对轨道位置，基本不受车轮打滑影响，精度最高。
2. **独立从动测量轮 + 高线数编码器**：实现简单；测量轮不参与驱动可降低打滑。
3. **驱动轮编码器**：最容易安装，但必须处理轮胎打滑和有效轮径变化。
4. **磁环 + 两霍尔正交安装**：尽量复用现有霍尔；数字AB计数，若AO近似sin/cos可做相位细分。现有模块适配性为 `TO_CONFIRM`。

注意：当前两只霍尔如果改作轮端正交编码器，就不能同时继续充当轨道A/B固定门；若要两类功能同时存在，需要增加编码器/霍尔或保留独立门传感器。

#### 原理A：数字正交计数

AB相差约90°，四边沿解码得到方向和累计计数 `C_k`：

`x_k=C_k·Δx`，`Δx=2πR/(4P)`。

在查询时刻 `t_q` 附近使用最近若干位置样本，令 `τ=t-t_q`，局部拟合：

`x(t)=c_0+c_1τ+c_2τ²+c_3τ³`。

则：

`v(t_q)=c_1`，`a(t_q)=2c_2`，`j(t_q)=6c_3`。

窗口持续滑动，就能在每个更新周期得到新的速度。高速使用较短窗口，低速自动增加时间/计数窗口。

#### 原理B：AO正余弦相位细分（条件方案）

若两路AO经标定后近似：

`A'=cosθ_e`，`B'=sinθ_e`，则：

`θ_e=unwrap[atan2(B',A')]`。

有 `P` 个电周期/机械圈时：

`x(t)=Rθ_e(t)/P`，`v(t)=(R/P)·dθ_e/dt`。

实际A/B常形成偏置、增益不等和相位误差的椭圆，必须先做椭圆中心、尺度和正交校准。若波形没有稳定单值相位关系，则放弃AO细分，仅使用合格编码器。

#### 原理C：实时卡尔曼状态估计

状态：

`s_k=[x_k,v_k,a_k]^T`。

预测模型：

```text
x(k+1)=x(k)+v(k)Δt+0.5a(k)Δt²
v(k+1)=v(k)+a(k)Δt
a(k+1)=a(k)+w(k)
```

`w(k)`允许加速度变化。编码器位置/相位到来时修正预测；没有新边沿时仍可短时输出预测，但置信区间要扩大。若AO相位以固定采样率更新，连续性更好。

#### 执行步骤

1. 明确要测车体真实速度还是驱动轮圆周速度；优先选独立测量轮或线性标尺。
2. 根据最大速度、最低速度、目标更新率和允许量化误差选择编码器线数/磁极数和测量轮半径。
3. 搭建机械件，检查同轴度、预压力、打滑和线缆应力；设置可重复的周长标定条件。
4. 数字AB通过电平转换模块进入FPGA；若编码器原生3.3 V推挽，可按其数据手册决定是否绕过转换板。
5. 实现4倍频正交解码、非法跳变检测、64 bit位置计数和边沿时间戳。
6. 用已知直线距离标定有效 `mm/count`，正反向分别检查比例和回差。
7. 先实现自适应M/T测速：高速按固定时间计数，低速按边沿周期；再实现局部三次或卡尔曼滤波。
8. 若采用双霍尔AO相位细分，先采集整圈A/B散点，完成椭圆校正、相位展开和数字计数对齐。
9. 在匀速、速度阶跃、加速度斜坡和正反切换下验证动态延迟、超调和噪声。
10. 用原固定霍尔门或独立位置参考周期性校验打滑/累计误差，异常时降低置信度或重置位置锚点。

#### 能力边界

- 能测：传感器持续有效期间的连续位置和任意更新时刻速度。
- 限制：任何算法都有带宽和延迟；“任意时刻”实际指每个采样/更新时刻及其有限窗估计。
- 测量轮/驱动轮打滑时编码器测到的是轮转速而非车体真实速度；线性标尺能避免这一根本问题。

### 7.2 引脚规划

集成方法1和方法2时：

| 信号 | 连接 |
|---|---|
| Hall A数字 | 电平板 `B0↔A0` → GPIO2 pin39 / `G15` |
| Hall B数字 | 电平板 `B1↔A1` → GPIO2 pin40 / `G16` |
| AO_A | 分压/RC → GPIO2 pin38/37 / `F16/E16` / VAUX0P/N |
| AO_B | 分压/RC → GPIO2 pin32/31 / `D16/D17` / VAUX8P/N |

方法3若使用新的AB编码器，需要另选空闲数字引脚，或在“霍尔改作轮端编码器”的替代机械方案中复用G15/G16。禁止在未核对原理图、I/O Bank电压和现有约束前随意指定新球位。

### 7.3 数据与状态

统一状态流：

```text
RESET → SELF_TEST → CALIBRATION_CHECK → ARMED/RUN
      → ACQUIRE → ESTIMATE → QUALITY_CHECK
      → VALID_REPORT / DEGRADED_REPORT / INVALID
```

- 方法1缓存：4个64 bit时间戳和标定参数，资源很小。
- 方法2缓存：按磁场有效宽度触发局部窗口；不得按最低速度连续保存两门全部数据。
- 方法3缓存：位置环形队列或卡尔曼状态；保存最近窗口和质量统计。
- 所有数值必须带单位；固定点实现显式给出Q格式、饱和和除零处理。
- TM1637只显示最终速度；UART同时输出方法编号、时间、加速度、质量和错误码。

### 推荐验收指标结构

在用户确定数值后，至少填写：

- 速度范围与正反方向；
- 任意时刻输出周期和总延迟；
- 匀速误差、变加速RMSE和峰值误差；
- 最大加速度和急动度；
- 静止零速漂移；
- 无效率和故障检出率；
- 每种方法的有效空间/时间范围。

## 9. 风险、进度与备选

| 严重度 | 风险 | 影响 | 下一动作 | 备选 |
|---|---|---|---|---|
| 致命 | 5 V数字或AO直接进入FPGA | 器件损坏 | 断电复核电平板与分压 | 未确认前禁止连接 |
| 高 | 把两固定门算法称为全程任意时刻测量 | 物理不可观测，结果依赖假设 | 明确有效窗口和预测标志 | 增加连续编码器 |
| 高 | Hall B仍占F16 | 与VAUX0P冲突 | 改至G16并更新XDC | 暂只启用一种功能 |
| 高 | AO加载或模板随气隙改变 | 相关/拟合偏差 | 空载加载对比、改机械限位 | 降级方法1 |
| 高 | 编码轮打滑 | 轮速不等于车速 | 独立从动轮或线性标尺；固定门检查 | IMU/视觉辅助 |
| 高 | 现有霍尔无法形成正交sin/cos | 方法3B无法细分 | 先做一圈波形原型测试 | 使用标准编码器 |
| 中 | 低速编码器边沿太稀 | 任意时刻更新滞后 | 高线数、AO细分、加长估计窗 | 卡尔曼短时预测 |
| 中 | 滤波/拟合窗口选错 | 动态被抹平或速度抖动 | 合成变加速扫参和独立验证集 | 自适应窗口 |
| 中 | 精度指标缺失 | 无法决定硬件线数和算法复杂度 | 先确定误差、更新率、动态范围 | 分阶段报告重复性 |

### 推荐实施顺序

1. **第1阶段：保底**——完成Hall B改G16、四边沿采集、正反位置标定和二次WLS；保留原门间平均速度。
2. **第2阶段：局部提精度**——搭建双AO分压/XADC，保存波形，完成互相关和空间模板拟合。
3. **第3阶段：任意时刻**——若需求确认是全程连续速度，选择线性编码器或独立测量轮编码器；先数字AB，再增加AO相位/卡尔曼。
4. **第4阶段：融合**——方法3连续输出；通过方法1/2固定位置结果修正比例、检查打滑和给出置信度。

最小演示：方法1独立运行；AO或编码器失败时仍能报告门间平均速度。备用件包括电平转换板、霍尔、精密分压电阻、电容、锁紧线缆、编码器和限流5 V电源。

## 附录A：最终推荐架构

如果最终目标明确为“变加速情况下，整段轨迹任意时刻的瞬时速度”，推荐：

```text
主测量：线性编码器或独立测量轮高分辨率编码器
算法：连续位置 → 局部三次拟合/卡尔曼 → v(t),a(t)

校准门：原双霍尔数字四边沿
精密校验：固定门双AO空间模板

判决：
编码器正常且与霍尔一致 → 高可信连续速度
编码器与固定门不一致   → 怀疑打滑/比例漂移，降置信度
编码器失效             → 仅在霍尔窗口报告局部/门间速度
```

这套结构把三种方法各自放在最擅长的位置：方法1负责可靠保底，方法2负责固定位置精细观测，方法3负责全程连续速度。
