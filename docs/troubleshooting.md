# 故障排查

## Open Target连接外设后找不到FPGA

如果拔掉电平转换板和TM1637后恢复扫描，问题在外接供电或接线，不要重装Vivado。

按断电分段法检查：

1. 仅开发板和JTAG；
2. 只接 `3V3→VCCA`、`+5V→VCCB`、公共GND；
3. 只给TM1637接5 V和GND，信号悬空；
4. 只增加 `C19→A2→B2→CLK`；
5. 只增加 `D18→A3→B3→DIO`；
6. 最后同时连接两根信号。

哪一步开始扫描失败，就撤销该步并检查对应线段。板灯变暗、USB反复连接、器件
发热或异味均属于立即断电条件。

## 串口正常但数码管不亮

- 确认TM1637使用5 V供电；
- 确认VCCA=3.3 V、VCCB=5 V且共地；
- 确认FPGA接A侧、TM1637接B侧；
- 确认 `C19→CLK`、`D18→DIO` 没有接反；
- 确认转换板排针已经可靠焊接。

当前TM1637驱动在ACK周期会释放DIO，但不读取ACK。因此程序无法自动判断
数码管是否断线；排查时应以供电、电平转换、接线和示波器/逻辑分析仪波形为准。

## 霍尔门没有触发

- 先观察模块状态灯，不要直接调整两个电位器；
- 翻转磁铁，分别测试`DN`与`DS`；
- 使用空闲高、触发低的数字输出；
- `AO`不得接入数字输入；
- 改变安装高度或阈值后重新标定门距。

## XSim把用户目录路径解析错

部分Windows环境中的Vivado 2022.2会错误删除
`C:\Users\<name>\...`下面的一个目录层级，随后报告无法写入`xsim.ini`。
这不是RTL错误，也不是目标目录权限不足。

将仓库克隆到用户目录之外的短路径，例如
`C:\fpga\zynq7020-hall-speed-meter`或`D:\fpga\zynq7020-hall-speed-meter`，
再运行仿真。不要通过反复修改文件权限掩盖错误路径。
