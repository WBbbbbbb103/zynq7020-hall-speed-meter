# car2 实物上板、采集与标定步骤

> 当前状态：`SIM`。正向、反向、匀速、变加速、数字四边沿及双 AO 联合仿真均已通过；尚无 `MEASURED` 实物数据，因此准确度没有得到验证。

## 1. 范围与验收条件

- 被测量：小车沿 A—B 方向的一维瞬时速度，单位 `m/s`。
- 当前 RTL 设置的粗测速范围：`0.05～5 m/s`；最终范围 `待补充`。
- 最终允许误差：`待补充`，必须在采集验证数据前确定。
- FPGA 时间戳：50 MHz，即 20 ns/计数。
- XADC 模拟输入采用单极性 0～1.0 V；为了保留裕量，分压节点实测最大值必须不高于 0.95 V，否则停止接线并调整分压。
- 有效结果仅限于最早与最晚有效边沿之间；区间外属于外推，不作为可靠结果。

## 3. 阶段一：先验证模拟输入安全

1. FPGA、传感器全部断电，禁止带电改线。
2. 两路数字输出仍按原方案经过电平转换模块；AO 禁止经过电平转换模块。
3. 每路 AO 使用 `10 kΩ / 2 kΩ` 分压和 `4.7 nF` 电容网络。
4. 暂时不要把分压节点接入 FPGA XADC。
5. 单独给霍尔模块供电，共地，用万用表测分压节点。
6. 让磁铁以所有可能的方向、距离经过传感器，记录两路最低和最高电压。
7. 两路都满足 `0～0.95 V` 后才能连接：
   - AO_A 分压节点 → `F16/VAUX0P`，`E16/VAUX0N` → GND；
   - AO_B 分压节点 → `D16/VAUX8P`，`D17/VAUX8N` → GND。
8. 任何一路超过 0.95 V：停止，不能依靠 FPGA 软件保护模拟输入。

## 4. 阶段二：数字输入与 ILA 冒烟测试

1. 只连接数字霍尔和公共地，AO 暂不连接。
2. 下载最新 `hall_ao_monitor_top.bit`，同时加载同目录 `.ltx`。
3. 在 ILA 中先观察 `hall_a_active`、`hall_b_active`。
4. 磁铁经过 A、B 时，每路应各出现一次进入和一次退出；静止时不得连续抖动。
5. 正向顺序通常为 `A_ON → A_OFF → B_ON → B_OFF`；若磁场范围重叠，允许时间排序变化，但每只传感器必须先 ON 后 OFF。
6. 按下并释放 KEY1 后重新开始一次采集。

## 6. 阶段四：标定数字四边沿空间位置

建立固定的一维位置坐标，建议 A 到 B 为正方向。传感器高度、磁铁方向、阈值旋钮固定后不得再改变。

分别从正向和反向极慢移动磁铁，使用位置参考记录：

- `AON_mm`、`AOF_mm`；
- `BON_mm`、`BOF_mm`。

要求：

1. 每个方向至少重复 15 次。
2. 采集前预先固定：前 10 次为 `train`，后 5 次为 `validation`，不得根据结果重新分组。
3. 正反方向分别求位置均值和标准差，不能共用一套位置。
4. 不删除异常值；先记录并调查抖动、松动、姿态变化或读数错误。
5. 将训练均值写入新的实测配置文件，禁止覆盖：

```text
config/four_edge_calibration_measured_YYYYMMDD.json
```

当前 `four_edge_calibration_sim.json` 仅用于模拟，不能改名冒充实测。

## 7. 阶段五：标定真实 AO 空间模板

当前 `ao_template_calibration_sim.json` 假设高斯磁场，只是 `SIM`。真实模块、磁铁和安装结构通常不会完全满足高斯形状。

1. 在每只传感器有效磁场范围及两侧基线区域建立等间距位置点，建议步距 1 mm；目标精度更高时可改为 0.5 mm。
2. 每个位置静止采集多次 ADC 码，保存原始读数、位置、方向和重复编号。
3. 正向和反向分别采集，以检查迟滞和机械回差。
4. `train` 使用整数毫米位置；`validation` 可使用错开的半毫米位置或独立日期重复，禁止参与模板拟合。
5. 优先使用实测查表和单调插值；只有残差没有结构性趋势时，才允许继续使用简单高斯模板。
6. 输出新的实测模板文件和独立验证误差，不覆盖原始 CSV。

## 8. 模型与结果解释

- 数字四边沿法：用四个已标定空间位置及四个时间戳拟合三次位置曲线，再求导得到瞬时速度。
- AO 法：把每个 AO 采样点通过实测空间模板转换成位置点，用大量位置—时间点拟合低阶轨迹，再求导。
- (t_c) 自动取最早与最晚有效边沿时刻的中点，只用于改善拟合数值条件，不是额外传感器标定量。
- 两种方法互相接近是“一致性证据”，不是独立准确度证据。
- 最终准确度只能由预先保留的 `validation` 数据和独立位置/速度参考给出。

## 9. 不确定度与有效范围

至少评估：

| 来源 | 类型 | 处理方式 |
|---|---|---|
| 四边沿位置重复性 | Type A | 重复测量标准差 |
| AO 重复噪声 | Type A | 静止重复 ADC 码标准差 |
| 位置参考仪器 | Type B | 根据仪器规格换算为标准不确定度 |
| 50 MHz 时基 | Type B | 根据晶振规格，当前 `待补充` |
| 安装高度、磁铁姿态 | 系统/重复性 | 固定结构并做重新安装试验 |
| 温漂与电源漂移 | 系统/重复性 | 不同温度或不同时间复测 |

报告中分别给出训练残差、独立验证最大误差、RMSE、重复性和扩展不确定度；在这些数据完成之前保持“准确度未验证”。

## 10. 重新标定条件

以下任一发生后必须重新标定：

- 更换霍尔模块或磁铁；
- 改变磁铁极性、方向、高度或数量；
- 移动 A/B 传感器；
- 调整模块阈值旋钮；
- 修改 AO 分压、滤波电容或采样率；
- 独立复核超出预先规定的允许误差。
