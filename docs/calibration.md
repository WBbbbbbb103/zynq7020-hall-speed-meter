# 距离与速度标定

## 为什么需要双向距离

霍尔门的逻辑触发位置由磁铁尺寸、极性、安装高度、模块阈值和运动方向共同决定，
因此机械中心距不一定等于有效测速距离。项目分别保留：

- `DIST_FWD_MM`：A门到B门方向；
- `DIST_REV_MM`：B门到A门方向。

## 标定步骤

1. 固定两只模块的高度、朝向和阈值旋钮；
2. 小车只安装一组磁铁，并固定磁铁朝向；
3. 缓慢从A向B移动，标记A、B数字输出首次有效跳变的位置；
4. 测量两标记之间的距离，重复至少5次并取平均；
5. 从B向A重复测量；
6. 将结果以毫米写入顶层参数；
7. 使用已知距离和不同速度进行复核。

默认的 `500 mm` 只是占位值。改变传感器高度、磁铁数量、磁铁方向、阈值旋钮或
支架位置后必须重新标定。

## 速度公式

```text
speed_mm_s = distance_mm × 50_000_000 / interval_ticks
```

串口和数码管显示单位均为 `mm/s`。例如 `F,2500` 表示正向2.500 m/s。
